s99wails minimal example

The Go shell around this page has wired up:

  • a localized tray icon: left-click toggles this window, the menu re-localizes on locale changes
  • close-to-tray: closing this window hides it; quit via the tray menu
  • windowstate: move/resize, quit, restart, and the geometry persists in windowstate.json
  • a theme watcher emitting theme:changed: flip your OS accent/dark mode
  • logger / program / theme services, callable once an app generates TS bindings

In a real app this page is your Nuxt/Vue frontend; see the README.
