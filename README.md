# S99Wails

`s99wails` is a set of reusable building blocks for Wails v3 desktop apps:
OS accent and dark-mode detection, native-side localization, a theme-aware
system tray, window-state persistence, autostart, environment workarounds,
and ready-made Wails services.

## Why

Every Wails app I built started by copying the previous app's desktop
shell: the tray manager, the accent watcher, the webkit workarounds (gtk 4 works very badly under amd on wayland, at least in my case, using gtk 3 fixed it), the
locale wrapper. The copies drifted apart. This module is that shared part,
extracted once, so the next app imports it instead. Pairs well with
[s99config](https://github.com/smegg99/S99Config) and
[s99logger](https://github.com/smegg99/S99Logger).

## Features

- `accent`: OS accent color and dark/light scheme, with a change watcher.
  Linux (XDG portal), Windows (registry), macOS (defaults). No Wails
  dependency.
- `locale`: go-i18n wrapper for native-side strings with plurals, template
  data, language matching, and an OnChange hook. No Wails dependency.
- `tray`: theme-aware tray icon with serialized updates, re-localizable
  menus, click-to-toggle, and close-to-tray, including the Wails v3 alpha
  workaround for Linux DBus menus.
- `windowstate`: window geometry persisted across runs behind a two-method
  Store interface.
- `autostart`: launch on login, per user, no elevation. XDG `.desktop`,
  registry Run key, LaunchAgent.
- `env`: WebKitGTK DMABUF workaround, AppImage detection, opt-in X11
  fallback for Plasma Wayland decorations.
- `services/{logger,program,theme}`: Wails-bound services with typed TS
  bindings generated by `wails3 generate bindings`.
- `traygen`: pregenerates tray icons per theme and state from labeled SVGs
  plus a CUE config, with typed Go accessors.
- `frontendgen`: emits the Vue composables (runtime detection, locale
  sync, system theme, log bridge) into your app's frontend tree, no npm
  packaging.

## Install

```sh
go get github.com/smegg99/s99wails
go get -tool github.com/smegg99/s99wails/traygen
go get -tool github.com/smegg99/s99wails/frontendgen
```

The module pins `wails/v3 v3.0.0-alpha2.117`. Wails v3 is alpha; keep your
app on the same version and bump both together. On Linux, build with
`-tags gtk3` (WebKit2GTK 4.1); the GTK 4 stack renders a blank window on
many GPU setups. Until a version is tagged, point replace directives at
your checkout:

```
replace (
	github.com/smegg99/s99wails => ../S99Wails
	github.com/smegg99/s99wails/traygen => ../S99Wails/traygen
)
```

## Quick Start

A localized tray with theme-aware icons, wired for locale changes:

```go
locales, _ := locale.New(localeDir, "en")

systemTray := app.SystemTray.New()
manager := tray.NewManager(systemTray, tray.Options{
    Icons:   trayicons.ForStatus(trayicons.StatusIdle), // traygen output, or your own IconsFunc
    Tooltip: func() string { return locales.T("tray.tooltip") },
})
manager.RegisterEvents(app)
defer manager.Close()

manager.SetMenu(func() *application.Menu {
    menu := app.NewMenu()
    menu.Add(locales.T("tray.show")).OnClick(func(_ *application.Context) { tray.Show(window) })
    return menu
})
locales.OnChange(manager.RebuildMenu)

tray.OnClickToggle(systemTray, window)
tray.CloseToTray(window, func() bool { return cfg.CloseToTray }, quitting.Load)
```

`examples/minimal` is the full wiring. The config package (CUE schema and
generated types), `main.go`, and your menu builder stay in the app;
`examples/configservice` is the starting point for the config part.

## Code generation

Both generators run through `go generate ./...` next to your other
generated code, and `wails3 generate bindings` emits typed TS models for
the services (including `accent.Info`).

traygen: declare states in `trayicons.cue`, label recolorable elements in
your SVGs with `inkscape:label`, and one icon per theme and state comes
out, plus typed accessors. Rendering is resvg in wasm: no system
dependencies, deterministic output.

```cue
prefix: "app-tray"
slots: ["badge"]
themes: {
    dark:  source: "logo-dark.svg"
    light: source: "logo-light.svg"
}
states: {
    idle: {}                          // slots without a color are hidden
    error: slots: badge: "#FF0000"
}
```

```go
// next to the SVGs and trayicons.cue:
//go:generate go tool traygen -config trayicons.cue

// switch states at runtime:
manager.SetIcons(trayicons.ForStatus(trayicons.StatusError))
```

frontendgen: the Vue composables ship the same way. The emitted files
import only `vue` and `@wailsio/runtime`; binding services are injected by
the caller.

```go
//go:generate go tool frontendgen -out ../frontend/app/composables/s99wails
```

## Examples

Run any terminal example with `go run ./examples/name`; the ones marked
gtk3 open a window and need `-tags gtk3` on Linux.

| Example | Shows |
| --- | --- |
| [`accent`](./examples/accent) | OS theme snapshot |

(`go test ./locale/ -run Example -v`).
